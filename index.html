How a New App Gets Built

  1. Pick the template closest to the app (or combine two: a dashboard with a list-detail view).
  2. Pick the layout per screen: plain views, list-detail or supporting pane; reading, default or wide width.
  3. Fill it with components and the decision rules in the skill. Monochrome unless the app asks for color.
  4. Run the page checker: 390 dark and 1280 light, contrast as rendered, overflow and rule lint.
